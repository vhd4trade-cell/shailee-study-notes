00પૂર્ણાંક = દિશા સાથેની સંખ્યા ↗

નામ
પૂર્ણ + અંક = આખી સંખ્યા · ધન = મિલકત (+) · ઋણ = દેવું (−) · 0 બેમાંથી એકેય નહીં
વિરોધી સંખ્યા
a + (−a) = 0
ક્રમ
−8 < −3 : જે વધુ જમણે તે મોટી

01સરવાળો-બાદબાકી ↗

બાદબાકી
a − b = a + (−b)
2 − (−3) = 2 + 3 = 5 (દેવું માફ = ફાયદો)
ચિપ્સ
+ અને − ની જોડી = 0, કાઢી નાખો; બચે તે જવાબ

02સરવાળા-બાદબાકીના ગુણધર્મો ↗

સંવૃતતા
a + b, a − b હંમેશાં પૂર્ણાંક (પૂર્ણ સંખ્યામાં 3 − 5 નહીં!)
ક્રમ
a + b = b + a
a − b ≠ b − a : 5 − (−3) = 8, (−3) − 5 = −8
જૂથ
a + (b + c) = (a + b) + c
બાદબાકીમાં નહીં
તટસ્થ
a + 0 = a = 0 + a
તટ + સ્થ = કોઈ બાજુ ન લે

03–04ગુણાકાર અને ચિહ્નનો નિયમ ↗↗

પેટર્ન: બીજી સંખ્યા 1 ઘટે → જવાબ 3 વધે → 0 પછી ધન
ધન × ઋણ
a × (−b) = −(a × b)
3 × (−5) = −15 (−5 નો કૂદકો 3 વાર)
ઋણ × ઋણ
(−a) × (−b) = a × b
"પાછળ ફર" બે વાર = સીધું
ઘણા ઋણ
ઋણ ગણો: બેકી → ધન, એકી → ઋણ · (−1)⁵ = −1
ગૂંચવણ
(−3) + (−2) = −5 પણ (−3) × (−2) = +6

05ગુણાકારના ગુણધર્મો ↗

સંવૃત, ક્રમ, જૂથ
a×b = b×a · (a×b)×c = a×(b×c)
0 અને 1
a × 0 = 0 · a × 1 = a
a × (−1) = −a (−1 તટસ્થ નથી)
વિભાજન
a(b + c) = ab + ac
a(b − c) = ab − ac · 6 × 13 = 60 + 18
ઝડપી ગણતરી
(−25) × 37 × 4 = (−100) × 37 = −3700

06–07ભાગાકાર અને તેના ગુણધર્મો ↗↗

ગુણાકારનું કુટુંબ: 2 × (−6) = −12 ⟹ બે ભાગાકાર
