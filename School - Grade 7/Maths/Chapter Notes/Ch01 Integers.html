00પૂર્ણાંક એટલે શું

શા માટે ભણવું: આખું પ્રકરણ એક જ વિચાર પર ઊભું છે — સંખ્યાને દિશા પણ હોય છે.

આ પ્રકરણ પછી તમે (1) ચિહ્ન સાથે ચારેય ક્રિયાઓ સાચી કરી શકશો, (2) "બે ઋણનો ગુણાકાર ધન કેમ?" નું કારણ પેટર્નથી બતાવી શકશો, (3) કયો ગુણધર્મ કઈ ક્રિયા માટે સાચો અને કયો ખોટો — તે ઉદાહરણથી સાબિત કરી શકશો, (4) તાપમાન, ગુણ, નફો-ખોટ, લિફ્ટ જેવા શાબ્દિક દાખલા ઉકેલી શકશો.

નામ પરથી જ અર્થ — પૂર્ણાંક, ધન, ઋણ

શબ્દોનો પાયો પૂર્ણાંક = પૂર્ણ (આખું) + અંક (સંખ્યા) → "આખી સંખ્યા", જેમાં કોઈ ટુકડો (અપૂર્ણાંક) નથી. અંગ્રેજી integer પણ લેટિન શબ્દ integer = "આખું, અખંડ" પરથી આવ્યો છે.
ધન = પૈસા, મિલકત → ધન પૂર્ણાંક (positive) = જે તમારી પાસે છે: +1, +2, +3 …
ઋણ = દેવું → ઋણ પૂર્ણાંક (negative) = જે તમારે ચૂકવવાનું છે: −1, −2, −3 …
આ નામો અકસ્માત નથી: લગભગ 1400 વર્ષ પહેલાં ભારતના ગણિતશાસ્ત્રી બ્રહ્મગુપ્તએ ઋણ સંખ્યાના નિયમો "ધન" (મિલકત) અને "ઋણ" (દેવું) ની ભાષામાં જ લખ્યા હતા. એટલે આ પ્રકરણનો દરેક નિયમ "પૈસા છે / દેવું છે" થી સમજી શકાય.
વ્યાખ્યા — પૂર્ણાંક સંખ્યાઓ
… , −3, −2, −1, 0, 1, 2, 3, …
ઋણ પૂર્ણાંકો + શૂન્ય + ધન પૂર્ણાંકો. 0 ધન પણ નથી, ઋણ પણ નથી.
પ્રાકૃતિક સંખ્યાઓ પૂર્ણ સંખ્યાઓની અંદર, અને પૂર્ણ સંખ્યાઓ પૂર્ણાંકોની અંદર. 0 પૂર્ણ સંખ્યામાં છે, પ્રાકૃતિકમાં નહીં.

સંખ્યારેખા: અંતર + દિશા

સંખ્યારેખા પર 0 વચ્ચે છે. જમણી તરફ ધન, ડાબી તરફ ઋણ. સંખ્યા બે વાત કહે છે: 0 થી કેટલું દૂર (અંતર) અને કઈ બાજુ (ચિહ્ન).

4 અને −4 શૂન્યથી સરખા 4 ડગલાં દૂર છે, ફક્ત દિશા ઊંધી.
વિરોધી સંખ્યા (additive inverse)
a + (−a) = 0
4 ની વિરોધી −4, −7 ની વિરોધી 7. બંને ભેગા = 0 (₹4 છે અને ₹4 નું દેવું — હિસાબ સરભર).
રોજિંદું ઉદાહરણ — ઋણ સંખ્યાઓ ક્યાં દેખાય છે થર્મોમીટર (0° થી નીચે ઠંડી), મોલની લિફ્ટ (B1, B2 = જમીનથી નીચેના માળ = −1, −2), બેન્કનો હિસાબ (જમા = ધન, ઉધાર = ઋણ), સમુદ્રની સપાટી (ઉપર ધન, નીચે ઋણ).
થર્મોમીટર એ ઊભી સંખ્યારેખા જ છે: ઉપર = વધુ ગરમ = મોટી સંખ્યા. −5° એ 0° કરતાં ઠંડું, એટલે −5 < 0.
સામાન્ય ભૂલ — "મોટું દેખાય તે મોટું" −8 માં "8" મોટો દેખાય છે, પણ −8 < −3. સંખ્યારેખા પર જે વધુ જમણે તે મોટી. ₹8 નું દેવું, ₹3 ના દેવા કરતાં ખરાબ છે.

01સરવાળો અને બાદબાકી — ઝડપી પુનરાવર્તન ધો. 6

શા માટે ભણવું: પાઠ 1.1 ના દરેક ગુણધર્મમાં આ જ ગણતરી આવે છે.

સંખ્યારેખા પર કૂદકાધન-ઋણ ચિપ્સબાદબાકી = વિરોધી ઉમેરો

1a. સરવાળો = સંખ્યારેખા પર કૂદકો

ધન ઉમેરો → જમણે જાઓ. ઋણ ઉમેરો → ડાબે જાઓ. 0 થી શરૂ કરો.

5 + (−8): પહેલા 5 જમણે, પછી 8 ડાબે → −3 પર પહોંચ્યા.

બીજી રીત — ચિપ્સ: દરેક + ચિપ = +1, દરેક − ચિપ = −1. એક + અને એક − ભેગા = 0 (શૂન્ય-જોડી). શૂન્ય-જોડીઓ કાઢી નાખો, જે બચે તે જવાબ.

5 ધન, 8 ઋણ → 5 શૂન્ય-જોડી નીકળી જાય, 3 ઋણ બચે.

1b. બાદબાકી = વિરોધી સંખ્યા ઉમેરો

નિયમ
a − b = a + (−b)
કોઈ સંખ્યા બાદ કરવી = તેની વિરોધી ઉમેરવી. એટલે 2 − (−3) = 2 + 3 = 5.

કેમ? (કારણ, ફક્ત યાદ રાખવાનું નહીં): "−(−3)" એટલે "₹3 નું દેવું કાઢી નાખવું". દેવું ઓછું થાય તો તમે ₹3 વધુ અમીર થયા. ચિપ્સથી જુઓ: 2 માંથી 3 ઋણ ચિપ્સ કાઢવી છે, પણ ઋણ ચિપ એક પણ નથી. તો 3 શૂન્ય-જોડી ઉમેરો (કિંમત 0 જ ઉમેરાઈ, બદલાઈ નહીં) — હવે 3 ઋણ કાઢો — 5 ધન બચે.

2 − (−3): 2 પછી 3 જમણે → 5.
શૂન્ય-જોડી ઉમેરીને ઋણ કાઢ્યા → 5.
રોજિંદું ઉદાહરણ તમારી પાસે ₹2 છે અને મિત્ર પાસેથી ₹3 ઉધાર લીધા હતા. મિત્ર કહે "ઉધાર માફ" — એટલે દેવું (−3) બાદ થયું. તમારી હાલત ₹2 થી ₹5 જેટલી સારી થઈ: 2 − (−3) = 5.
સામાન્ય ભૂલ 2 − (−3) = −1 લખવું. બે "−" એકબીજાની બાજુમાં હોય ત્યાં "બાદ કરો ઋણ" = "ઉમેરો ધન". પહેલાં a + (−b) માં ફેરવો, પછી કૂદકા મારો.
જાતે ચકાસો (i) (−7) + 4 = ? (ii) (−4) − (−9) = ? (iii) 0 − 6 = ?
જવાબ: (i) −3 (ii) 5 (iii) −6

02સરવાળા-બાદબાકીના ગુણધર્મો

શા માટે ભણવું: "ખાલી જગ્યા પૂરો" અને "ખરું-ખોટું" ના મોટા ભાગના પ્રશ્નો અહીંથી આવે છે. (પાઠ 1.1, પાન 1–4)

સંવૃતતાક્રમનો ગુણધર્મજૂથનો ગુણધર્મતટસ્થ સંખ્યા 0
"ગુણધર્મ" એટલે શું ગુણ (લક્ષણ) + ધર્મ (હંમેશાં પાળતો સ્વભાવ) = એવો નિયમ જે દરેક પૂર્ણાંક માટે, હંમેશાં સાચો હોય. એક ઉદાહરણ ખોટું પડે તો ગુણધર્મ નથી.

2a. સંવૃતતા (Closure)

શબ્દનો અર્થ સંવૃત = ચારે બાજુથી બંધ, ઘેરાયેલું. અંગ્રેજી closed પણ એ જ: પૂર્ણાંકોની "વાડ" માંથી જવાબ ક્યારેય બહાર નથી જતો.
ગુણધર્મ — સરવાળો અને બાદબાકી સંવૃત છે
a + b અને a − b હંમેશાં પૂર્ણાંક
ઉદા. 17 + 23 = 40, (−8) − (−14) = 6, 7 − 9 = −2 — બધા પૂર્ણાંક.

આ કેમ "મોટી વાત" છે? પૂર્ણ સંખ્યાઓ (0, 1, 2 …) બાદબાકી માટે સંવૃત નથી: 3 − 5 = −2, જે પૂર્ણ સંખ્યા નથી. ઋણ સંખ્યાઓ ઉમેરી ત્યારે જ બાદબાકી "હંમેશાં શક્ય" બની.

3 − 5 નો જવાબ −2 પૂર્ણ સંખ્યાની વાડ (વાદળી) ની બહાર પડે છે — પણ પૂર્ણાંકોમાં તે આરામથી છે.
રોજિંદું ઉદાહરણ બેન્ક ખાતામાં ₹3 છે અને ₹5 નો ચેક કપાય: બેલેન્સ −₹2 (ઉધાર). પૂર્ણાંકો હોવાથી બેન્ક દરેક જમા-ઉધારનો જવાબ લખી શકે છે — જવાબ ક્યારેય "લખી ન શકાય" તેવો આવતો નથી.

2b. ક્રમનો ગુણધર્મ (Commutative) — સરવાળામાં હા, બાદબાકીમાં ના

શબ્દનો અર્થ ક્રમ = ગોઠવણી, આગળ-પાછળ. પાઠ્યપુસ્તક "સમક્રમી" કહે છે: સમ (સરખું) + ક્રમ → ક્રમ બદલો તોય જવાબ સરખો. અંગ્રેજી commute = અદલાબદલી કરવી.
ગુણધર્મ
a + b = b + a
5 + (−6) = −1 અને (−6) + 5 = −1.
પહેલા +5, પછી −6 → −1
પહેલા −6, પછી +5 → −1
રોજિંદું ઉદાહરણ પહેલા ₹5 ખિસ્સાખર્ચ મળે અને પછી ₹6 વાપરો — કે પહેલા ₹6 ઉધાર વાપરો અને પછી ₹5 મળે — બંનેમાં છેવટે ₹1 નું દેવું (−1).
બાદબાકી સમક્રમી નથી
a − b ≠ b − a
5 − (−3) = 8, પણ (−3) − 5 = −8. જવાબ સરખા અંતરે, પણ ઊંધી બાજુએ.
ક્રમ બદલો તો ચિહ્ન ઊંધું થાય: 8 અને −8 શૂન્યથી સરખા દૂર, સામસામે.
રોજિંદું ઉદાહરણ લિફ્ટ: 5મો માળ અને B3 (= −3). "5 − (−3) = 8" એટલે 5મો માળ B3 થી 8 માળ ઉપર; "(−3) − 5 = −8" એટલે B3, 5મા માળથી 8 માળ નીચે. અંતર સરખું, દિશા ઊંધી — એટલે ક્રમ મહત્ત્વનો.

2c. જૂથનો ગુણધર્મ (Associative) — સરવાળામાં હા

શબ્દનો અર્થ જૂથ = ટોળકી, group. કૌંસ [ ] કોણ પહેલા ભેગા થશે તે નક્કી કરે. અંગ્રેજી associate = સાથે જોડાવું.
ગુણધર્મ
a + (b + c) = (a + b) + c
(−5) + [(−3) + (−2)] = −10 અને [(−5) + (−3)] + (−2) = −10.
પહેલા (−3)+(−2) = −5 નું જૂથ
પહેલા (−5)+(−3) = −8 નું જૂથ
રોજિંદું ઉદાહરણ ક્વિઝના ત્રણ રાઉન્ડના ગુણ −20, 10, −5. પહેલા બે રાઉન્ડ ભેગા કરો કે છેલ્લા બે — કુલ −15 જ આવે. એટલે ટોટલ કરતી વખતે જે જોડી સહેલી લાગે તે પહેલા ભેગી કરી શકાય.
ધ્યાન રાખોબાદબાકી માટે જૂથનો ગુણધર્મ નથી: (8 − 5) − 2 = 1, પણ 8 − (5 − 2) = 5.

2d. સરવાળા માટે તટસ્થ સંખ્યા 0 (Additive Identity)

શબ્દનો અર્થ તટસ્થ = તટ (કિનારો) + સ્થ (ઊભેલું) → નદીના કિનારે ઊભેલો, ઝઘડામાં કોઈની બાજુ ન લે. 0 પણ કોઈ સંખ્યાને બદલતો નથી. અંગ્રેજી identity (લેટિન idem = "એ જ") — સંખ્યા "એની એ જ" રહે.
ગુણધર્મ
a + 0 = a = 0 + a
(−8) + 0 = −8, 0 + (−37) = −37.
0 ઉમેરવું = 0 ડગલાં ચાલવું → જ્યાં હતા ત્યાં જ.
રોજિંદું ઉદાહરણક્રિકેટમાં "ડૉટ બૉલ": 0 રન ઉમેરાયા, સ્કોર એ જ રહ્યો.
જાતે ચકાસો ખાલી જગ્યા: (i) (−23) + ___ = (−23) (ii) [(−4) + 15] + (−3) = (−4) + [15 + ___] (iii) ખરું કે ખોટું: 7 − 3 = 3 − 7
જવાબ: (i) 0 (ii) −3 (iii) ખોટું (4 ≠ −4)
→ આગળ: Part 03 — ગુણાકાર. પહેલા સહેલો કિસ્સો: એક ધન, એક ઋણ.

03ગુણાકાર: ધન × ઋણ

શા માટે ભણવું: ચિહ્નના નિયમનો પહેલો અડધો ભાગ. (પાઠ 1.2.1, પાન 5–7)

ગુણાકાર = વારંવાર સરવાળોપેટર્નa × (−b) = −(a × b)

3a. ગુણાકાર = એ જ સંખ્યાનો વારંવાર સરવાળો

3 × 5 = 5 + 5 + 5. એ જ રીતે 3 × (−5) = (−5) + (−5) + (−5) = −15: −5 નો કૂદકો 3 વાર.

3 × (−5): ડાબી તરફ 5-5 ના 3 કૂદકા → −15.

3b. (ઋણ) × (ધન) — પેટર્નથી

(−3) × 5 ને "−3 વાર ઉમેરો" ન કહી શકાય. તો પેટર્ન જુઓ: પહેલી સંખ્યા 1 ઘટે ત્યારે જવાબ દર વખતે 5 ઘટે છે. 0 પછી પણ પેટર્ન ચાલુ રાખો:

3×5 = 15, 2×5 = 10, 1×5 = 5, 0×5 = 0, પછી (−1)×5 = −5, (−2)×5 = −10, (−3)×5 = −15.
નિયમ — એક ધન, એક ઋણ
a × (−b) = (−a) × b = −(a × b)
ચિહ્ન ભૂલી જઈને ગુણો, પછી આગળ "−" મૂકો. 10 × (−43) = −(10 × 43) = −430. (a, b ધન પૂર્ણાંક)
રોજિંદું ઉદાહરણ તમે 3 દિવસ સુધી રોજ ₹5 વાપરો (−5 રોજ). કુલ ફેરફાર = 3 × (−5) = −₹15. અથવા: શિયાળામાં તાપમાન રોજ રાત્રે 4° ઘટે, તો 5 રાતમાં 5 × (−4) = −20° નો ફેરફાર.
સામાન્ય ભૂલ(−3) × 5 = 15 લખવું — ચિહ્ન ભૂલી જવું. પહેલા ચિહ્ન નક્કી કરો, પછી સંખ્યા ગુણો.
જાતે ચકાસો(i) 15 × (−16) (ii) (−42) × 12
જવાબ: (i) −240 (ii) −504
→ આગળ: Part 04 — સૌથી રસપ્રદ પ્રશ્ન: બે ઋણ ગુણીએ તો?

04ગુણાકાર: ઋણ × ઋણ = ધન

શા માટે ભણવું: આ નિયમ ગોખવાને બદલે "કેમ" સમજો તો ક્યારેય ભૂલ નહીં થાય. (પાઠ 1.2.2, પાન 7–9)

પેટર્ન"પાછળ ફરો" નો અર્થચિહ્નનું કોષ્ટકઋણ સંખ્યાઓ ગણો

4a. પેટર્ન — પાઠ્યપુસ્તકની રીત

(−3) × 4 થી શરૂ કરો અને બીજી સંખ્યા 1-1 ઘટાડો. જવાબ દર વખતે 3 વધે છે. 0 પછી પણ 3-3 વધતો જ રહે — એટલે ધન બને.

−3×4 = −12, −3×3 = −9, … −3×0 = 0, −3×(−1) = 3, −3×(−2) = 6.
નિયમ — બે ઋણ
(−a) × (−b) = a × b
ચિહ્ન વગર ગુણો, જવાબ ધન. (−10) × (−12) = 120, (−15) × (−6) = 90.

4b. "−1 વડે ગુણવું" = પાછળ ફરવું (કારણ)

સંખ્યારેખા પર ચાલતા માણસની કલ્પના કરો. બીજી સંખ્યા = એક ડગલાનું માપ અને મોઢાની દિશા (ધન → મોઢું જમણે, ઋણ → મોઢું ડાબે). પહેલી સંખ્યા = કેટલાં ડગલાં, અને ધન હોય તો આગળ ચાલો, ઋણ હોય તો પાછળ (ઊંધા પગે) ચાલો.

3 × (−2): મોઢું ડાબે, 3 ડગલાં આગળ → −6
(−3) × (−2): મોઢું ડાબે, 3 ડગલાં પાછળ → +6

મોઢું ડાબે છે અને તમે પાછળ ચાલો — તો શરીર જમણી તરફ જાય! બે "ઊંધાપણાં" ભેગા થઈને સીધું બને. આ જ કારણે ઋણ × ઋણ = ધન.

રોજિંદું ઉદાહરણ (1) દેવું માફ: તમારા પર ₹2-₹2 ના 3 દંડ (−2) હતા. શિક્ષક ત્રણેય દંડ રદ (−3 વાર) કરે: (−3) × (−2) = +₹6 — તમારી હાલત ₹6 સુધરી.
(2) કવાયત (PT): "પાછળ ફર!" એક વાર → મોઢું પાછળ. બે વાર → ફરી આગળ. દરેક (−1) = એક "પાછળ ફર".
ચિહ્નનું કોષ્ટક: સરખાં ચિહ્ન → ધન, જુદાં ચિહ્ન → ઋણ. દરેક ખાનામાં સાચો ગુણાકાર લખેલો છે.
ઘણા ઋણ હોય ત્યારે — ઋણ સંખ્યાઓ ગણો
ઋણની સંખ્યા બેકી → જવાબ ધન · એકી → જવાબ ઋણ
(−1)×(−1) = 1, (−1)×(−1)×(−1) = −1. દરેક બે ઋણ મળીને એક ધન બનાવે છે; એક બચે તો જવાબ ઋણ. ઉદા. 9 × (−3) × (−6) = 162 (બે ઋણ → ધન).
(−1) ને 1, 2, 3 … વાર ગુણો: ચિહ્ન દર વખતે ઊંધું — એકી વાર → −1, બેકી વાર → +1.
રોજિંદું ઉદાહરણPT ની "પાછળ ફર" ની જેમ જ: 4 વાર પાછળ ફરો (બેકી) → મોઢું આગળ; 5 વાર (એકી) → મોઢું પાછળ.
સામાન્ય ભૂલ — સરવાળા સાથે ગૂંચવવું (−3) + (−2) = −5 (દેવું + દેવું = વધુ દેવું), પણ (−3) × (−2) = +6. "બે ઋણ = ધન" નિયમ ફક્ત ગુણાકાર-ભાગાકાર માટે છે, સરવાળા માટે નહીં.
વધારાનું — પરીક્ષા માટે જરૂરી નથી પાઠ્યપુસ્તક પાન 8–9 પરની રમત 1: −104 થી 104 નું બોર્ડ, વાદળી પાસો = ધન, લાલ પાસો = ઋણ. બંને પાસાંનો ગુણાકાર કરી કાઉન્ટર ખસેડો. આ રમત ચિહ્નનો નિયમ ઝડપથી આદત બનાવે છે.
જાતે ચકાસો(i) (−31) × (−100) (ii) (−25) × (−72) (iii) (−12) × (−11) × 10
જવાબ: (i) 3100 (ii) 1800 (iii) 1320
→ આગળ: Part 05 — ગુણાકાર કયા ગુણધર્મ પાળે છે.

05ગુણાકારના ગુણધર્મો

શા માટે ભણવું: પરીક્ષાના "ચકાસો" પ્રશ્નો અને ઝડપી ગણતરી. (પાઠ 1.3, પાન 10–13)

સંવૃતતાક્રમ× 0× 1 અને × (−1)જૂથવિભાજન

5a. સંવૃતતા અને ક્રમનો ગુણધર્મ

ગુણધર્મ
a × b પૂર્ણાંક જ · a × b = b × a
બે પૂર્ણાંકનો ગુણાકાર હંમેશાં પૂર્ણાંક; ક્રમ બદલો તોય સરખો: 3 × (−4) = (−4) × 3 = −12.
3 × (−4): −4 નો કૂદકો 3 વાર
(−4) × 3: મોઢું જમણે, 4 ડગલાં પાછળ
રોજિંદું ઉદાહરણવર્ગમાં 3 હાર × 4 બેંચ = 4 હાર × 3 બેંચ = 12 બેંચ. ચિહ્ન સાથે પણ એ જ: 3 દિવસ × (−₹4) = (−₹4) × 3 = −₹12.

5b. શૂન્ય વડે ગુણાકાર

ગુણધર્મ
a × 0 = 0 × a = 0
(−3) × 0 = 0, 0 × (−4) = 0. ધન હોય કે ઋણ — શૂન્ય વડે ગુણો એટલે 0.
પેટર્નનું કેન્દ્ર: 0 × 5 = 0. પેટર્ન 0 માંથી જ પસાર થાય છે.
રોજિંદું ઉદાહરણ0 પેકેટ ખરીદો તો એક પેકેટની કિંમત ગમે તે હોય — ખર્ચ ₹0.

5c. ગુણાકારની તટસ્થ સંખ્યા 1, અને −1 ની ખાસિયત

ગુણધર્મ
a × 1 = 1 × a = a · a × (−1) = −a
1 વડે ગુણો → એ જ સંખ્યા (1 તટસ્થ). (−1) વડે ગુણો → વિરોધી સંખ્યા: 18 × (−1) = −18, (−25) × (−1) = 25. એટલે (−1) તટસ્થ નથી.
× (−1) = 0 ની સામે અરીસામાં પ્રતિબિંબ: 3 ↔ −3, −6 ↔ 6. × 1 = જ્યાં છો ત્યાં જ.
રોજિંદું ઉદાહરણ1 વસ્તુ ખરીદો → બિલ = તેની કિંમત (×1). "પાછળ ફર" (×(−1)) → દિશા ઊંધી, અંતર એ જ.
0 અને 1 — બે તટસ્થસરવાળામાં તટસ્થ = 0, ગુણાકારમાં તટસ્થ = 1. પરીક્ષામાં આ બંને ગૂંચવાય છે.

5d. જૂથનો ગુણધર્મ

ગુણધર્મ
(a × b) × c = a × (b × c)
[(−3) × (−2)] × 5 = 6 × 5 = 30 અને (−3) × [(−2) × 5] = (−3) × (−10) = 30.
30 લાડુ: 3 બ્લોક × 10, કે 6 હાર × 5 — કઈ રીતે જૂથ બનાવો, ગણતરી 30 જ. (ચિત્રમાં ધન સંખ્યા; ઋણ હોય ત્યારે ચિહ્ન Part 04 ના નિયમથી આવે.)
રોજિંદું ઉદાહરણ3 ટ્રે, દરેકમાં 2 હાર, દરેક હારમાં 5 લાડુ: (3 × 2) × 5 = 3 × (2 × 5) = 30.

5e. વિભાજનનો ગુણધર્મ (Distributive)

શબ્દનો અર્થ વિભાજન = વહેંચવું. કૌંસ બહારની સંખ્યા કૌંસની દરેક સંખ્યાને "વહેંચાય" છે (દરેક સાથે ગુણાય છે). અંગ્રેજી distribute = વહેંચી આપવું.
ગુણધર્મ
a × (b + c) = a × b + a × c
a × (b − c) = a × b − a × c
(−2) × (3 + 5) = (−6) + (−10) = −16; 4 × (3 − 8) = 12 − 32 = −20.
6 × 13 = 6 × (10 + 3): લંબચોરસના બે ભાગ 60 + 18 = 78. (માપ પ્રમાણે દોરેલ.)

લંબચોરસ ફક્ત ધન લંબાઈ બતાવી શકે. ઋણ સંખ્યા માટે સંખ્યારેખા જુઓ:

(−2) × 8 = 8 કૂદકા, દરેક −2. પહેલા 3 કૂદકા (−6), પછી 5 કૂદકા (−10) → કુલ −16.
રોજિંદું ઉદાહરણ — મનમાં ઝડપી ગણતરી ₹13 ની એક એવી 6 નોટબુક: 6 × 10 = 60, 6 × 3 = 18, કુલ ₹78. દુકાનદાર આ જ રીતે ગણે છે.
ગુણધર્મોથી ગણતરી સહેલી: (−25) × 37 × 4 = [(−25) × 4] × 37 = (−100) × 37 = −3700.
સામાન્ય ભૂલ(−2) × (3 + 5) = (−2) × 3 + 5 લખવું — બીજા પદને ગુણવાનું ભૂલી જવું. કૌંસની દરેક સંખ્યા સાથે ગુણો.
જાતે ચકાસોચકાસો: 10 × [6 + (−2)] = 10 × 6 + 10 × (−2)?
જવાબ: ડાબી બાજુ 10 × 4 = 40; જમણી બાજુ 60 + (−20) = 40 — સરખા.
→ આગળ: Part 06 — ભાગાકાર, જે ગુણાકારને "ઊંધો" કરે છે.

06પૂર્ણાંકોનો ભાગાકાર

શા માટે ભણવું: ગુણાકારનો નિયમ આવડે તો ભાગાકાર "મફત" આવડી જાય. (પાઠ 1.4, પાન 14–15)

ભાગાકાર = ઊલટી ક્રિયાચિહ્નનો નિયમ

6a. ભાગાકાર એ ગુણાકારની ઊલટી (વ્યસ્ત) ક્રિયા

3 × 5 = 15 હોય તો 15 ÷ 5 = 3 અને 15 ÷ 3 = 5. દરેક ગુણાકારમાંથી બે ભાગાકાર બને — ત્રણ સંખ્યાનું એક "કુટુંબ".

2 × (−6) = −12 ⟹ (−12) ÷ (−6) = 2 અને (−12) ÷ 2 = −6.
12 લાડુ, 3 ડબ્બા: દરેકમાં 4.
(−12) ÷ 3: −12 સુધીનો રસ્તો 3 સરખા કૂદકામાં → દરેક કૂદકો −4.

6b. ચિહ્નનો નિયમ — ગુણાકાર જેવો જ

નિયમ
(−a) ÷ b = a ÷ (−b) = −(a ÷ b)
(−a) ÷ (−b) = a ÷ b (b ≠ 0)
(−20) ÷ 5 = −4, 72 ÷ (−8) = −9, (−45) ÷ (−9) = 5. ચિહ્ન વગર ભાગો; ચિહ્ન જુદાં → ઋણ, સરખાં → ધન.

કેમ ગુણાકાર જેવો જ? કારણ કે ભાગાકારનો જવાબ ગુણાકારથી ચકાસાય છે: (−45) ÷ (−9) = 5 કેમ કે 5 × (−9) = −45. જો જવાબ −5 હોત તો (−5) × (−9) = +45 થાત — ખોટું.

ભાગાકારનું ચિહ્ન-કોષ્ટક ગુણાકાર જેવું જ.
રોજિંદું ઉદાહરણ3 કલાકમાં તાપમાન 12° ઘટ્યું (−12°). દર કલાકે ફેરફાર = (−12) ÷ 3 = −4°. ₹120 નું દેવું 3 મિત્રો સરખું વહેંચે: (−120) ÷ 3 = −₹40 દરેક.
સામાન્ય ભૂલભાગાકાર પછી જવાબ ગુણાકારથી ચકાસતા નથી. આદત પાડો: ભાગફળ × ભાજક = ભાજ્ય?
જાતે ચકાસો(i) (−100) ÷ 5 (ii) 125 ÷ (−25) (iii) (−36) ÷ (−4)
જવાબ: (i) −20 (ii) −5 (iii) 9
→ આગળ: Part 07 — ભાગાકાર કયા ગુણધર્મ નથી પાળતો.

07ભાગાકારના ગુણધર્મો

શા માટે ભણવું: "ખરું-ખોટું" માં અહીંથી પ્રશ્નો આવે છે — મોટા ભાગના જવાબ "ના". (પાઠ 1.5, પાન 16–17)

સંવૃત નથીક્રમ નથી÷ 0 નહીં÷ 1, ÷ (−1)જૂથ નથી

7a. ભાગાકાર સંવૃત નથી

ગુણધર્મ નથી
a ÷ b હંમેશાં પૂર્ણાંક નથી
(−8) ÷ 3 = −8/3, જે પૂર્ણાંક નથી.
−8/3 ≈ −2.67 એ −3 અને −2 ની વચ્ચે પડે — કોઈ પૂર્ણાંક પર નહીં.
રોજિંદું ઉદાહરણ8 રોટલી 3 જણ વચ્ચે સરખી વહેંચો તો દરેકને 2 રોટલી અને થોડો ટુકડો — આખો આંકડો ન મળે.

7b. ભાગાકાર સમક્રમી નથી

ગુણધર્મ નથી
a ÷ b ≠ b ÷ a
(−8) ÷ (−4) = 2, પણ (−4) ÷ (−8) = 1/2.
ક્રમ બદલ્યો → 2 ને બદલે ½.
રોજિંદું ઉદાહરણ8 લાડુ 4 બાળકોમાં → દરેકને 2; 4 લાડુ 8 બાળકોમાં → દરેકને અડધો.

7c. શૂન્ય અને ભાગાકાર

નિયમ
a ÷ 0 વ્યાખ્યાયિત નથી · 0 ÷ a = 0 (a ≠ 0)
"વ્યાખ્યાયિત નથી" = તેનો કોઈ અર્થ (જવાબ) જ નથી.

કેમ? (કારણ): 12 ÷ 0 = ? નો અર્થ "કઈ સંખ્યાને 0 વડે ગુણીએ તો 12 આવે?" — પણ Part 05 મુજબ કોઈ પણ સંખ્યા × 0 = 0, 12 ક્યારેય નહીં. એટલે આવો જવાબ અસ્તિત્વમાં નથી. ઊલટું, 0 ÷ 5 = 0 કેમ કે 0 × 5 = 0 — બરાબર ચાલે.

રોજિંદું ઉદાહરણ12 લાડુ "0 ડબ્બા" માં સરખા મૂકો — ડબ્બો જ નથી, તો દરેક ડબ્બામાં કેટલા? પ્રશ્નનો કોઈ અર્થ નથી. (ચિત્ર: ઉપરનું 12 ÷ 3 નું લાડુ-ચિત્ર — ડબ્બા 0 કરો તો લાડુ મૂકવાની જગ્યા જ ન રહે. "કંઈ નથી" નું અલગ ચિત્ર દોરી ન શકાય, એટલે અહીં નવી આકૃતિ નથી.)
સામાન્ય ભૂલ"5 ÷ 0 = 0" કે "= 5" લખવું. સાચો જવાબ: વ્યાખ્યાયિત નથી.

7d. 1 અને −1 વડે ભાગાકાર

નિયમ
a ÷ 1 = a · a ÷ (−1) = −a
(−8) ÷ 1 = −8; (−8) ÷ (−1) = 8, 11 ÷ (−1) = −11.

કેમ? 8 × (−1) = −8, એટલે (−8) ÷ (−1) = 8. (−1) વડે ભાગવું = (−1) વડે ગુણવું — બંને સંખ્યાને અરીસામાં ફેરવે (Part 05 નું અરીસા-ચિત્ર).

રોજિંદું ઉદાહરણઆખી રકમ 1 જ વ્યક્તિને આપો → તેને આખી રકમ મળે (÷1).

7e. ભાગાકાર જૂથનો ગુણધર્મ પાળતો નથી

ગુણધર્મ નથી
(a ÷ b) ÷ c ≠ a ÷ (b ÷ c)
[(−16) ÷ 4] ÷ (−2) = (−4) ÷ (−2) = 2, પણ (−16) ÷ [4 ÷ (−2)] = (−16) ÷ (−2) = 8.
એ જ ત્રણ સંખ્યા, કૌંસ ખસેડ્યો → 2 અને 8.
રોજિંદું ઉદાહરણઆ નિયમનું સાચું રોજિંદું ઉદાહરણ સહેલું નથી — તે ફક્ત ગણતરીની કાળજી માટે છે: કૌંસ હોય ત્યાં પહેલા કૌંસ.
ખરું કે ખોટું(i) પૂર્ણાંકો ભાગાકાર માટે સંવૃત છે. (ii) 0 ÷ (−12) = 0 (iii) (−9) ÷ 3 = 3 ÷ (−9)
જવાબ: (i) ખોટું (ii) ખરું (iii) ખોટું (−3 ≠ −1/3)
→ આગળ: Part 08 — બધું ભેગું કરી શાબ્દિક દાખલા.

08શાબ્દિક દાખલા

શા માટે ભણવું: પરીક્ષાના 3–4 ગુણના પ્રશ્નો. (પાઠ્યપુસ્તક ઉદાહરણ 2, 3 — પાન 17–18)

ધન/ઋણ નક્કી કરોઆપેલ → શોધવાનું → રીત → ગણતરી → જવાબ → ચકાસણી
પહેલું પગલું હંમેશાં દરેક જથ્થાને ચિહ્ન આપો: મળે / વધે / ઉપર / નફો / સાચું = ધન; જાય / ઘટે / નીચે / ખોટ / ખોટું = ઋણ. પછી જ ગણતરી.

8a. પરીક્ષાના ગુણ (ઉદાહરણ 2)

ઉદાહરણ 2 (i) — પાન 17
આપેલ: સાચા જવાબના +5, ખોટાના −2. 10 સાચા, કુલ 30 ગુણ.
શોધવાનું: ખોટા જવાબ કેટલા?
રીત: કુલ = સાચાના ગુણ + ખોટાના ગુણ.
ગણતરી: સાચાના ગુણ = 5 × 10 = 50. ખોટાના ગુણ = 30 − 50 = −20. ખોટા જવાબ = (−20) ÷ (−2) = 10.
જવાબ: 10 ખોટા જવાબ.
ચકાસણી: 50 + 10 × (−2) = 50 − 20 = 30 ✓
50 ગુણ મેળવ્યા, 20 ગુમાવ્યા → 30.
ક્યાં વપરાયઓલિમ્પિયાડ અને સ્પર્ધાત્મક પરીક્ષાઓમાં "ખોટા જવાબના ગુણ કપાય" (negative marking) — બરાબર આ જ ગણતરી.

8b. નફો અને ખોટ (ઉદાહરણ 3)

ઉદાહરણ 3 (i) — પાન 17–18
આપેલ: એક પેન પર ₹1 નફો (+1), એક પેન્સિલ પર 40 પૈસા ખોટ (−40 પૈસા). 45 પેન વેચી, મહિને કુલ ₹5 ખોટ.
શોધવાનું: કેટલી પેન્સિલ વેચી?
ગણતરી: પેનનો નફો = +₹45. પેન્સિલની ખોટ = કુલ − પેન = (−5) − 45 = −₹50 = −5000 પૈસા. પેન્સિલ = (−5000) ÷ (−40) = 125.
જવાબ: 125 પેન્સિલ.
ચકાસણી: 45 + 125 × (−0.40) = 45 − 50 = −5 ✓ (રૂપિયા અને પૈસા એક જ એકમમાં ફેરવો.)
પેનનો +₹45, પેન્સિલનો −₹50 → કુલ −₹5.

8c. તાપમાન (પોતાનું ઉદાહરણ)

ઉદાહરણ
આપેલ: હિલ-સ્ટેશન પર સાંજે 6 વાગ્યે 4°C. દર કલાકે 2°C ઘટે (−2).
શોધવાનું: ક્યારે −6°C થશે?
ગણતરી: કુલ ફેરફાર = (−6) − 4 = −10°. કલાક = (−10) ÷ (−2) = 5.
જવાબ: સાંજે 6 + 5 કલાક = રાત્રે 11 વાગ્યે.
ચકાસણી: 4 + 5 × (−2) = 4 − 10 = −6 ✓
દર કલાકે 2° નીચે, 5 કૂદકા: 4° થી −6°.

8d. લિફ્ટ / ખાણ (પોતાનું ઉદાહરણ)

ઉદાહરણ
આપેલ: ખાણની લિફ્ટ જમીનથી 15 મી ઉપર (+15) થી શરૂ થઈ, દર મિનિટે 5 મી નીચે જાય. જમીનથી 45 મી નીચે (−45) પહોંચવું છે.
ગણતરી: કુલ ફેરફાર = (−45) − 15 = −60 મી. સમય = (−60) ÷ (−5) = 12 મિનિટ.
જવાબ: 12 મિનિટ.
ચકાસણી: 15 + 12 × (−5) = 15 − 60 = −45 ✓
+15 મી થી −45 મી = 60 મી નીચે; 5 મી પ્રતિ મિનિટ → 12 મિનિટ.
સામાન્ય ભૂલ"નીચે 45 મી" ને 45 લઈ લેવું (ચિહ્ન ભૂલવું) → ફેરફાર 45 − 15 = 30 → 6 મિનિટ. ખોટું! જમીનની ઉપર અને નીચે બંને ભાગ ગણાય: 15 + 45 = 60.

વિભાજનa × (b + c) = a × b + a × c, a × (b − c) = a × b − a × c
યાદ રાખો
  1. બાદબાકી = વિરોધી સંખ્યા ઉમેરવી: a − b = a + (−b).
  2. × અને ÷ માં: સરખાં ચિહ્ન → ધન, જુદાં ચિહ્ન → ઋણ. ઘણા ઋણ: બેકી → ધન, એકી → ઋણ.
  3. સરવાળામાં તટસ્થ 0, ગુણાકારમાં તટસ્થ 1; (−1) વડે ગુણો/ભાગો → વિરોધી સંખ્યા.
  4. a ÷ 0 વ્યાખ્યાયિત નથી; 0 ÷ a = 0.
  5. શાબ્દિક દાખલામાં પહેલા દરેક જથ્થાને ચિહ્ન આપો, છેલ્લે જવાબ ચકાસો.
જાતે ચકાસો (1) ખાલી જગ્યા: (−206) ÷ ___ = 1   (2) (−1) × (−1) × (−1) × (−1) × (−1) = ?   (3) સમજાવો: (−4) × (−3) = 12 કેમ? (પેટર્નથી)
જવાબ: (1) −206 (2) −1 (પાંચ ઋણ = એકી) (3) −4×1 = −4, −4×0 = 0, −4×(−1) = 4, −4×(−2) = 8, −4×(−3) = 12 — દર વખતે 4 વધે.
