# Shailee — Std 7 study notes (GSEB, Gujarati medium)

Study material for Shailee, written in Gujarati, following the GSSTB textbooks.

Read it here: https://vhd4trade-cell.github.io/shailee-study-notes/

## What is here
Only the documents we made. The textbooks themselves are not in this repo.

| Folder | What it is |
|---|---|
| `School - Grade 7/<Subject>/Chapter Notes/` | Full chapter explanations with diagrams and real-life examples |
| `School - Grade 7/<Subject>/Revision Sheets/` | One-page quick revision before a test |
| `School - Grade 7/<Subject>/Practice and Answer Keys/` | Answers to textbook exercises |
| `School Tests/` | Exam plans (syllabus and marks pattern) |

Study each chapter in this order: Chapter Notes, then Revision Sheet, then Answer Key.

## How to read
Open any `.html` file in a web browser, or use the link above. The links between documents work as long as the folders are kept as they are.
